# Ask Baba | बाबा से पूछें — Track · Reflect · Transform

> **A Spiritual Companion for a Better You**  
> Mobile-first responsive web application & PWA based on Brahma Kumaris spiritual knowledge.

## Features
- **Daily Spiritual Dashboard:** Dynamic greeting, Today's Purusharth, customizable routine checklist, and progress tracking.
- **Rajyoga Meditation Studio:** Midnight-themed meditation experience with authentic 432Hz Paramdham drone soundscapes, guided audio library, and silent timer bells.
- **My Journey:** Level progression gauge, streak statistics, and interactive weekly growth chart.
- **Ask Baba AI:** Grounded Brahma Kumaris spiritual AI offering structured 6-part answers with voice recognition and audio playback.
- **Track & Sanskar Transformation:** Self-observation questionnaires and daily spiritual practice logs.
- **Daily Reflection:** Personal evening journal with emotion selectors and sankalp affirmations.
- **Spiritual Knowledge Library:** Curated lessons across all 7 core Rajyoga spiritual categories.
